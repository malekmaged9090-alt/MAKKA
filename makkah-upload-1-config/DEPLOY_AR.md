# دليل النشر على السحابة (Supabase + GitHub + Netlify)

> أنا (Claude) لا أملك وصولاً إلى حساباتك، فالخطوات التالية تنفّذها أنت. كل خطوة مكتوبة بحيث تعرف ما يجب أن تراه.

## 1) قاعدة البيانات (Supabase)
1. مشروع جديد (أو القائم إن كانت قاعدته فارغة من أي بيانات تحتاجها).
2. **SQL Editor ← New query** وألصق محتوى `supabase/setup/01_ALL_IN_ONE.sql` كاملاً ← **Run**.
   - يعمل كمعاملة واحدة؛ إن ظهر خطأ فلا يتغيّر شيء، فأرسل لي نصّه.
   - إن كانت في القاعدة بقايا من محاولة سابقة: شغّل أولاً `00_RESET_public_schema.sql` (⚠️ يمسح كل جداول public ولا يمسح مستخدمي Auth).
3. **Authentication ← Users ← Add user**: بريدك وكلمة مرور قوية، وفعّل **Auto Confirm User**.
4. افتح `supabase/setup/02_bootstrap_admin.sql`، غيّر `CHANGE_ME@example.com` إلى بريدك نفسه ← **Run**. يجب أن ترى: `Owner ready`.
5. شغّل استعلامات `supabase/verify_production.sql` — **كل استعلام يجب أن يرجع صفر صفوف**.
6. **Authentication ← URL Configuration**: ضع `Site URL` = رابط موقعك على Netlify (مثلاً `https://makka-osama.netlify.app`) وأضفه أيضاً في Redirect URLs.
7. **Project Settings ← API**: انسخ `Project URL` و`anon / publishable key` فقط. ⚠️ لا تنسخ ولا تستعمل `service_role` في أي مكان.

## 2) GitHub
- في المستودع: احذف الملفات القديمة وارفع **محتوى** مجلد المشروع بحيث يكون `package.json` في **جذر** المستودع (وليس داخل مجلد فرعي).
- لا ترفع `.env.local` (موجود في `.gitignore`).

## 3) Netlify
1. Site configuration ← Environment variables، أضف:
   - `NEXT_PUBLIC_SUPABASE_URL` = رابط المشروع
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = المفتاح العام
   - `NEXT_PUBLIC_SITE_URL` = رابط موقعك على Netlify
2. Deploys ← **Clear cache and deploy site**. (ملف `netlify.toml` يحدد Node 20 وأمر البناء.)
3. إن أخفق البناء فأرسل لي آخر 30 سطراً من سجل البناء.

## 4) تجربة يدوية بعد النشر (15 دقيقة)
1. سجّل الدخول بحساب المالك ← تظهر القائمة كاملة.
2. **المناطق ← استيراد**: نزّل القالب، أدخل مناطقك، معاينة ثم استيراد.
3. **التجار ← تاجر جديد**، ثم **المستخدمون**: أضف موظفاً (أنشئ حسابه في Supabase Authentication أولاً ثم اربطه) وجرّب بحسابه أنه لا يرى إلا ما يخصه.
4. **شحنة جديدة** (أو **استيراد شحنات**) ← افتح الشحنة ← **بوليصة** ← اطبعها وامسح الباركود بجهازك.
5. **السائقون**: أضف سائقاً، حدد مناطقه، اربط حسابه؛ ثم **التوزيع** ← أسند الشحنة.
6. سجّل دخول السائق من جوّال: **تطبيق السائق** ← خروج للتوصيل ← تسليم مع مبلغ COD.
7. افتح رابط التتبع من QR الشحنة في نافذة خاصة (بدون دخول): يجب أن يظهر الوضع **بدون** هاتف أو عنوان.
8. **المالية**: أغلق عهدة السائق وأنشئ تسوية للتاجر.

## 5) بعد الإطلاق
- فعّل النسخ الاحتياطي (Database ← Backups) وفكّر في مشروع Staging منفصل.
- ضع حداً لعدد الطلبات على `/track` من إعدادات Netlify/Cloudflare.
- راجع سياسة الخصوصية والاحتفاظ بالبيانات و VAT مع المحاسب.
